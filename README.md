# Криптография — лабораторные работы

Учебный репозиторий с лабораторными алгоритмами на Python, отчётом и исходниками блок-схем.

## Основные материалы

- `Отчет_Криптография_СергеевНА.docx` — актуальная версия отчёта.
- `Пояснение_всех_алгоритмов.docx` — подробное руководство по алгоритмам из лабораторных работ.
- `Пояснение_отчёта_и_подготовка_к_защите.docx` — структура отчёта, план выступления и ответы на вопросы.
- `Архив_отчетов/` — прежние редакции отчёта и справочный отчёт Губина.
- `PDF/` — методические материалы, стандарты и задания.
- `Блок-схемы_исходники/` — редактируемые схемы draw.io и изображения.
- `Лабы Тема 1` … `Лабы Тема 4` — исходный код лабораторных работ.

## Темы

### Тема 1 — симметричные и классические шифры

Атбаш, Цезарь, квадрат Полибия, Тритемий, Белазо, Виженер, S-блок МАГМА, матричный шифр Хилла, Плейфер, вертикальная перестановка, решётка Кардано, сеть Фейстеля, гаммирование, A5/1, A5/2, МАГМА, ГОСТ 28147-89, AES и Кузнечик.

### Тема 2 — алгоритмы с открытым ключом

RSA, Эль-Гамаль, эллиптические кривые и Диффи—Хеллман.

### Тема 3 — цифровая подпись

RSA, ГОСТ Р 34.10-94 и ГОСТ Р 34.10-2012.

## Запуск

Требуется Python 3. Запускайте нужный `.py` файл из соответствующей папки лабораторной работы. Программы учебные и демонстрируют алгоритмы; для защиты реальных данных используйте проверенные криптографические библиотеки и корректные режимы работы.
